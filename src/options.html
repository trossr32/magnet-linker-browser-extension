Magnet Linker

Send magnet links straight to Transmission via the RPC API.

Extension

Site access needed

Magnet Linker needs permission to run on websites so it can find magnet links and add its buttons. Nothing is collected or sent anywhere except your own Transmission server.

Transmission API

Fill out the fields to build the URL that points to your Transmission RPC API. Credentials are sent as a Basic Authorization header, never embedded in the URL.

Tokens [host] and [port] are replaced with the values above.

URL preview

Magnet search

Configure how magnet links are found on web pages. Both fields accept comma-separated lists. Attributes find linked magnets (e.g. href); element types find magnet links written out as text (e.g. code blocks on Reddit).

Attributes whose value is searched for a magnet link.

Element types whose text is searched for a magnet link. Keep this specific — broad types can inject a lot of buttons.

Site customisation

Customise the HTML injected around the button on a per-site basis. The search value matches all or part of the site's hostname (e.g. zooqle). Changes save automatically.

No site customisations yet.

Magnet storage

Optionally store every magnet sent to Transmission so buttons can be marked as ‘Already sent’ when a page is revisited. History is kept on this device only.

Stored magnets: 0

Notifications

Toast notifications shown on the page when interacting with the injected buttons. Disabling toast notifications overrides both the error and success settings.

Debug

Log extension activity to the browser console (prefixed [MagnetLinkExt]). Warnings and errors are always logged.

Backup & restore

Export your settings and magnet history to a JSON file, or restore them from a previous export.

Permissions

What the extension is allowed to do, and why.

Site access

Magnet links can appear on any website, so the extension asks to run on all sites. It only reads pages to find magnet links; the only network requests it makes are to your configured Transmission server.
