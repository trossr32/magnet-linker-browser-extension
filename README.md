A cross-browser extension (Chrome, Edge, Firefox, Firefox for Android) that extends magnet links on websites with a button that sends the torrent straight to your [Transmission](https://transmissionbt.com/) instance via the RPC API.

## Overview

- Any magnet link found on a page gets a **Send to Transmission** button injected next to it.
- Magnet detection is configurable: by element attribute (e.g. `href` for linked magnets) and by element type (e.g. `code` for magnets written out as text, such as on Reddit).
- Optional per-site customisation of the injected HTML (insert markup before/after the button, control its float).
- Optional magnet storage marks buttons as **Already sent** when a page is revisited.
- Toast notifications on success and failure, a dynamic toolbar icon that lights up when a page contains magnet links, and settings backup/restore.

## Getting started

Install from your browser's store:

- [Chrome web store](https://chrome.google.com/webstore/detail/magnet-linker/neokhcngmjnlbnphpfmiidlljbpffecd)
- [Microsoft Edge add-ons store](https://microsoftedge.microsoft.com/addons/detail/iagaihihgeloakmheonacpldkpogggen)
- [Firefox add-ons store](https://addons.mozilla.org/en-GB/firefox/addon/magnet-linker/)

Once installed, open the options page and configure the Transmission API connection. On Chrome and Edge the extension will also ask you to grant site access — magnet links can appear on any website, so it requests permission to run on all sites; nothing is read beyond finding magnet links and nothing is sent anywhere except your own Transmission server.

## Settings

### API

Fill out the host, port and (if required) username/password fields to build the URL that points to your Transmission RPC API. Credentials are sent as a Basic Authorization header. Use **Test connection** to verify everything works.

### Magnet search

Configure how magnet links are found, with two comma-separated lists:

- **Element attributes** (default `href`) finds linked magnets:

  ```html
  <a href="magnet:?xt=urn:btih:d540fc48eb12f2833163eed6421d449dd8f1ce1f&dn=Ubuntu+19.04">Magnet link</a>
  ```

- **Element types** (default `code`) finds magnets written out as text:

  ```html
  <code>magnet:?xt=urn:btih:d540fc48eb12f2833163eed6421d449dd8f1ce1f&dn=Ubuntu+19.04</code>
  ```

### Site customisation

Customise the HTML injected around the button on a per-site basis — markup before/after the button and its float. The search value matches all or part of the site's hostname (e.g. `zooqle`).

### Magnet storage

Optionally store every magnet sent to the API so buttons can be marked **Already sent** on revisited pages, with a toggle controlling whether those buttons stay clickable. The storage tab lists the history and can clear it.

### Notifications

Toast notifications shown when interacting with the injected buttons, with separate toggles for error and success toasts.

## Create package

Grunt is the task runner:

```powershell
npm i
grunt release
```

`grunt release` builds `dist/chromium` (Manifest V3) and `dist/firefox` (Manifest V2) and packages both into `Publish/` via web-ext. On Windows it runs `CreatePackage_Grunt.ps1`; on other platforms `create_package_Grunt.sh`.

Other useful commands:

```powershell
grunt debug           # lint + build both browsers to dist/
npm run chromium      # run the built extension in Chromium via web-ext
npm run firefox       # run the built extension in Firefox
npm run lint          # web-ext lint against dist/firefox
```

## Tests

Unit tests (Jest):

```powershell
npm test
```

Integration tests (Playwright) load the built extension into Chromium and run against a local fixture page (`Test/magnet-test.html`) — no third-party sites involved:

```powershell
grunt playwright
cd tests/playwright
npm i
npx playwright install --with-deps chromium
npx playwright test
```
